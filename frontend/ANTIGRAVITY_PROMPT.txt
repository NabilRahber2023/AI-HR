## STEP 1 — Extract the zip
Unzip `hr-nextjs-frontend.zip` into your project root.
Your project structure should look like:

  hr-ai-platform/
  ├── app/               ← FastAPI backend (KEEP AS IS)
  ├── frontend/          ← OLD Vite frontend (DELETE THIS)
  ├── hr-nextjs-frontend/ ← NEW Next.js frontend (RENAME TO frontend/)
  ├── models/
  ├── data/
  └── ...

## STEP 2 — Swap the frontend folders
  # Windows (PowerShell)
  Remove-Item -Recurse -Force frontend
  Rename-Item hr-nextjs-frontend frontend

  # Mac/Linux
  rm -rf frontend
  mv hr-nextjs-frontend frontend

## STEP 3 — Fix backend CORS
Open `app/main.py` and update the CORSMiddleware section:

  app.add_middleware(
      CORSMiddleware,
      allow_origins=[
          "http://localhost:3000",   # Next.js default port
          "http://localhost:5173",   # Vite (kept for compatibility)
          settings.FRONTEND_URL,
      ],
      allow_credentials=True,
      allow_methods=["*"],
      allow_headers=["*"],
  )

## STEP 4 — Update .env (backend)
In your backend `.env` file, set:
  FRONTEND_URL=http://localhost:3000

## STEP 5 — Install & run Next.js frontend
  cd frontend
  npm install
  npm run dev

  ✅ Frontend: http://localhost:3000
  ✅ Backend:  http://localhost:8000

## STEP 6 — Ensure backend is running
In a separate terminal (from project root, venv activated):
  uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

## STEP 7 — Login and test
  1. Open http://localhost:3000
  2. You'll be redirected to /login
  3. Use: admin@company.com / admin123
  4. You'll land on the Admin Dashboard
  5. Upload data/synthetic_employees.csv via Upload CSV
  6. Go to ML Prediction → Train Model
  7. Search employees, view chatbot, check metrics

# ================================================================
# TROUBLESHOOTING
# ================================================================

PROBLEM: "Module not found" errors
FIX: Run `npm install` inside the frontend/ folder

PROBLEM: Charts not rendering (SSR error with recharts)
FIX: Already handled with 'use client' directive on all pages.
     If still occurring, add to the component:
     import dynamic from 'next/dynamic'

PROBLEM: CORS error in browser console
FIX: Make sure app/main.py has http://localhost:3000 in allow_origins
     Restart the backend after editing: uvicorn app.main:app --reload

PROBLEM: 401 Unauthorized on API calls
FIX: Log out, log back in to get a fresh JWT token.
     Token is stored in localStorage under 'hr-auth-storage'

PROBLEM: Blank page / hydration error
FIX: These pages use 'use client' and Zustand persist. Clear
     localStorage and refresh: localStorage.clear()

PROBLEM: Port 3000 already in use
FIX: Run: npm run dev -- --port 3001
     Then update NEXT_PUBLIC_API_URL and CORS accordingly

PROBLEM: @tailwindcss/forms not found
FIX: Run: npm install @tailwindcss/forms
